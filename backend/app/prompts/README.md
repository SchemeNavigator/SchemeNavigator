# Prompts

Purpose

This folder stores every prompt used by Scheme Navigator's future AI layer.

## Rules

- No prompt text should be hardcoded inside Python files.
- Prompts should be stored as standalone files and loaded explicitly.
- Each prompt should have a clear purpose and a predictable filename.
- Prompt templates should remain versionable, testable, and easy to review.

## Planned Prompt Files

- `intent.md`
- `query_expansion.md`
- `ranking.md`
- `planner.md`
- `verification.md`

## Current Phase

This phase only creates the folder contract. No prompts are implemented yet.
